# Contact Book

A Python command-line tool to manage contacts.

## Features
- Add a contact (name, phone, email)
- View all saved contacts
- Search for a contact by name
- Delete a contact by name
- Save all contacts to a file (contact.txt)

## How it works
Contacts are stored as dictionaries inside a list while the program runs. The program loops through a menu until the user exits, and can save the current list to a text file.

## How to run
python contact_book.py

## Note
Contacts are not automatically reloaded from the file when the program restarts — this is planned for a future version.
